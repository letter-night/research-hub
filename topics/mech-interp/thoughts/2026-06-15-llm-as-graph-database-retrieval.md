# LLM은 거대한 graph database retrieval system 같다

> 기존 블로그 글에서 옮긴 요약입니다. 원문 표현을 최대한 살렸지만 전문은 아닙니다.
- [어떻게 보면, LLM은 거대한 graph database retrieval system 같기도 해](https://letter-night.tistory.com/1370) (2026-06-15)

## 나의 생각
- 내 생각이 비약인지 궁금하다. LLM과 Agent AI에 대한 다른 사람들의 견해를 듣고 싶다.
- MI를 공부하며 든 생각: LLM 내부에는 **거대한 causal graph network**가 구축되어 있다. 프롬프트가 이 네트워크를 거쳐 정보를 retrieve하고 출력으로 내놓는 거대한 시스템이다.
- Agent는 여기에 memory와 tool을 더한 확장판이다.
- 데이터베이스가 keyword, index로 정보를 압축 저장하고 효율적으로 불러오듯, graph DB는 **hierarchy & relation**을 반영해 인간의 직관적 정보 체계와 잘 맞는다.
- 결국 LLM은 내부에 **계층적인 causal concept**를 저장하고, 네트워크를 통해 추론한 결과를 검색해 내는 것 같다.
