## 피드백과 토론 (Advisor)

### 1. 당신의 연구는 하나의 질문으로 수렴하고 있습니다
188편을 시간순으로 보면, 2025년 6월 *Robust Agents Learn Causal World Models*를 읽고 쓴 질문 — **"어떻게 causal model을 학습시킬 것인가?"** — 이 1년 반 동안 모습을 바꿔 계속 돌아옵니다.

| 시기 | 모습 |
|---|---|
| 2025.6–7 | robust agent는 causal model을 알아야 한다 → causal discovery, CRL |
| 2025.10–2026.1 | SCM prior로 학습하면 되지 않을까? → PFN, causal FM |
| 2026.1 | CRL이 안 보여서 LLM으로 → "MI가 답을 주었다!" |
| 2026.6–7 | 그렇다면 LLM 내부를 검증하자 → SCM faithfulness 제안서 |
| 2026.11 | 고전으로 돌아가 Pearl의 plan evaluation에서 agent와 다시 연결 |

주제를 자주 옮긴 것처럼 보일 수 있지만, 실제로는 **같은 질문을 다른 도구로 공략한 것**입니다. 이것이 이 저장소를 관통하는 축이 되도록 CLAUDE.md에 "Big Question"으로 적어 두었습니다.

### 2. 우선순위 제안: I01 또는 I02 하나에 집중
- 회사 일과 병행하고 계산 자원이 제한적이라는 점(2026-07 회고)을 고려하면, **작은 모델과 합성 데이터로 끝낼 수 있는 질문**이 맞습니다. I01과 I02가 여기에 해당하고, 둘 다 이미 실험 설계의 씨앗이 있습니다.
- **I02를 먼저 추천합니다.** PFN은 합성 SCM으로 학습되어 정답 그래프를 아는 상태에서 실험할 수 있고, 모델이 작습니다. 다만 TabPFN 연구가 이미 나왔으므로 질문을 **"효과 추정 PFN이 adjustment set을 표현하고 쓰는가"** 로 좁혀야 합니다.
- I01은 I02에서 만든 방법론(관측 동일·개입 상이 그래프 쌍, probe → patching)을 LLM으로 옮기는 2단계로 두면 하나의 연구 프로그램이 됩니다.

### 3. 반론: "MI가 보여주는 것이 곧 인과 추론인가?"
2026-01 글에서 "MI가 causal representation & discovery에 답을 주었다"고 쓰셨습니다. 지도교수라면 이렇게 물을 것입니다.
- attribution graph의 edge는 **모델 계산 안에서의** 인과 관계입니다. 그것이 **세계의** 인과 관계를 표현한다는 것은 별도의 주장이고, 이를 잇는 것이 바로 causal abstraction 프레임입니다. 이 둘을 구분해서 쓰면 제안서가 훨씬 단단해집니다.
- I01의 "관측 분포 동일 / 개입 분포 상이" 통제가 이 간극을 메우는 핵심 장치입니다.

### 4. 실패한 연구(I04)에서 건질 것
시계열 인과 FM은 결과를 못 냈지만, 기록을 보면 중요한 것을 배웠습니다: 과거 treatment history를 무시하면 time-fixed 추정도 편향된다는 것. 이것은 I06(plan evaluation agent)의 직접적인 근거가 됩니다. I04는 `parked`로 두되, I02의 방법론이 자리 잡으면 "시변 처치 PFN"으로 다시 꺼낼 수 있습니다.
